# login-page-simple

A simple login page UI built with **plain HTML and CSS** — front-end only, no back-end, no JavaScript, no frameworks.

## Preview

The page is hosted on Netlify: _link added after deployment_

## Files

| File         | Purpose                          |
| ------------ | -------------------------------- |
| `index.html` | Login page markup                |
| `style.css`  | Styling (centered card, gradient background) |

## Run locally

Just open `index.html` in a browser — no build step needed.
